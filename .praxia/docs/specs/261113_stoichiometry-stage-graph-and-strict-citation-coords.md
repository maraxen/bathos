# Spec: Stoichiometry Stage-Graph Conservation, Reagent Amortization, and Strict Citation Coordinates (`bathos`)

## Goal

Add a physical stoichiometry DAG validator (`<stem>.bth.toml [stoichiometry]` / `[[stoichiometry.stages]]` / `[stoichiometry.subpools.<name>]` validated via `validate_sidecar` and `bth check --check-stoichiometry`), reagent pack-size amortization validation (`<stem>.bth.toml [reagents.<name>]`), and self-contained coordinate-windowed verbatim citation verification (`verify_citations --strict-coords` / `bth verify-citations`) in `bathos` so bottlenecks, barcode collisions, uncleaned background DNA species, reagent pack mismatches, and out-of-window or SHA-mismatched quotes fail closed before experimental or proposal execution.

## Non-goals

- Modeling reaction kinetics, continuous-culture ODE timecourses, or fluidics flow rates inside `<stem>.bth.toml` (only discrete molecular/CFU/read stage-to-stage conservation, Poisson occupancy collision probabilities, enzymatic species filtering, and pack-size amortization are in scope).
- Rewriting `<stem>.bth.toml` sidecars, project-root `.bth.toml`, or `.numbered.txt` primary source extracts during `bth check`, `bth validate-sidecar`, or `bth verify-citations`.
- Placing `[stoichiometry]` or `[reagents.<name>]` inside project-root `.bth.toml` (there is zero inheritance or merging from `.bth.toml`), non-sidecar `.bth.toml` artifacts (`claim.bth.toml`, `*.attestation.bth.toml`, `parity.bth.toml`), or non-`EXPERIMENT` sidecar kinds (`SidecarKind.BENCHMARK`, `SidecarKind.VALIDATION`, `SidecarKind.DEBUG`).
- Requiring `[stoichiometry]` or `[reagents.<name>]` on legacy `<stem>.bth.toml` sidecars or `new_experiment` templates that omit them (semantic validation triggers only when those optional tables are present on `SidecarKind.EXPERIMENT` sidecars or when explicit `bth check --check-stoichiometry` / `--sidecar-path` flags request checks).
- Changing run freshness (`check_runs`) or output SHA drift (`check_output_sha_drift`) semantics for existing `bth check` callers invoked with neither `--check-stoichiometry` nor `--sidecar-path`.
- Running semantic stoichiometry conservation or reagent amortization checks inside `bth lint` or changing `bathos.linter.iter_project_sidecars` (`src/bathos/linter.py` and `tests/test_linter_sidecar_walk.py` stay untouched; parse-time `SidecarError` exceptions from `parse_sidecar` continue to surface in existing `linter` callers).
- Expanding `GateErrorCode` (`src/bathos/prereg.py:21-40`) beyond its existing 15 members (`prereg.gate_check` maps stoichiometry and reagent validation errors to `GateErrorCode.SIDECAR_INVALID`).

## Design decisions

1. **D1 — File placement and `SidecarKind` applicability**: Both `[stoichiometry]` (including `[[stoichiometry.stages]]` and `[stoichiometry.subpools.<name>]`) and `[reagents.<name>]` belong exclusively in per-script `<stem>.bth.toml` (or directory-level `[experiment]`) sidecars parsed by `parse_sidecar` (`src/bathos/sidecar.py`), never in project/subdirectory config `.bth.toml` (`src/bathos/config.py`) or non-sidecar `.bth.toml` artifacts (`claim.bth.toml`, `*.attestation.bth.toml`, `parity.bth.toml`), with zero inheritance or merging across files. Restrict BOTH `[stoichiometry]` and `[reagents]` strictly to `SidecarKind.EXPERIMENT` (matching `[requires]` and `[budget]` at `src/bathos/sidecar.py:848-852`): if `"stoichiometry"` or `"reagents"` appears on any other `SidecarKind`, `parse_sidecar` raises `SidecarError` naming the file and disallowed `SidecarKind`.
2. **D2 — Module-scope frozen dataclasses and unknown-key strictness**: Define frozen dataclasses `SubpoolSpec`, `StoichiometryStage`, `StoichiometryBlock`, and `ReagentSpec` at module scope in `src/bathos/sidecar.py` (never behind `TYPE_CHECKING`), using JSON-round-trippable types (`tuple[str, ...]`, `tuple[StoichiometryStage, ...]`, `dict[str, SubpoolSpec]`, `dict[str, ReagentSpec]`, primitives, `None`), and add `stoichiometry: StoichiometryBlock | None = None` and `reagents: dict[str, ReagentSpec] = field(default_factory=dict)` to `Sidecar` (`src/bathos/sidecar.py:258-366`) so `typing.get_type_hints` inside `_hydrate_dataclass` (`src/bathos/sidecar.py:540-556`, via `_hydrate` at `507-537`) round-trips `Sidecar.from_declaration` (`src/bathos/sidecar.py:331-351`) cleanly. Reject unknown keys on `[stoichiometry]`, `[[stoichiometry.stages]]`, `[stoichiometry.subpools.<name>]`, and `[reagents.<name>]` at parse time with `SidecarError` (matching `_parse_outputs` at `src/bathos/sidecar.py:922-927`).
3. **D3 — Poisson birthday-paradox collision metrics and `barcoding_mode`**: Compute both distinct metrics with `-math.expm1(-colony_cfu / barcode_diversity)`: (a) `per_clone_collision_prob = -math.expm1(-colony_cfu / barcode_diversity)` (probability a clone shares its barcode with at least one other clone; equals `0.259182` or `25.92%` at `colony_cfu = 1.5e6`, `barcode_diversity = 5e6`), (b) `expected_duplicate_fraction = 1.0 - (barcode_diversity / colony_cfu) * (-math.expm1(-colony_cfu / barcode_diversity))` (expected fraction of clones lost as duplicates beyond one unique clone per occupied barcode; equals `0.136061` or `13.61%` at `1.5e6` / `5e6`), and (c) `occupied_barcodes = barcode_diversity * (-math.expm1(-colony_cfu / barcode_diversity))` (`1295908.90` at `1.5e6` / `5e6`). Bind `max_collision_prob` strictly to `per_clone_collision_prob` (default `0.05` blocking; `warn_collision_prob` defaults to `0.5 * max_collision_prob` = `0.025`). Support `barcoding_mode` in `{"pre_barcoded_vector", "primer_pcr"}`: `"pre_barcoded_vector"` requires a `barcode_collision` stage on `colony_cfu`, while `"primer_pcr"` assigns `0.0` pre-barcoded transformation collision and evaluates any declared primer-UMI `barcode_collision` stage against its incoming stage entities.
4. **D4 — 8-kind DAG topology, transition equations, cleanup rules, and subpool sizing**: Model stages as a DAG via `depends_on` validated by Kahn topological sort across the closed 8-value `StageKind` set (`input_molecules`, `enzymatic_species_cleanup`, `colony_cfu`, `barcode_collision`, `founder_inoculum`, `pcr_template_molecules`, `bulk_fluorometry`, `phix_adjusted_net_reads`). Enforce `ENZYME_REMOVES_SPECIES` and `DISALLOWED_CONTAMINANTS_BY_STAGE_KIND` at `colony_cfu`, `bulk_fluorometry`, `pcr_template_molecules`, and `phix_adjusted_net_reads` regardless of whether `bulk_fluorometry` is present. Size weighted subpools via exact cross-multiplied `Decimal` comparison (`actual_d * w_i < min_i * total_w`, with `w_i = Decimal(str(subpool.weight))`, `total_w = sum(w_j)`, `min_i = Decimal(min_group_size_i)`, `actual_d = Decimal(str(actual_pool_size))`), eliminating IEEE-754 and `Decimal` division drift at exact integer boundaries.
5. **D5 — `bth check` discovery, `mcp_check_tool` parity, `bth run` blocking, and rollback flag**: Reconcile `mcp_check_tool` (`src/bathos/mcp.py:4120-4134`) with `check_tool` (`src/bathos/mcp.py:2344-2437`) by adding and forwarding `check_outputs: bool = False`, `check_stoichiometry: bool = False`, and `sidecar_path: str = ""`. Keep `bathos.linter.iter_project_sidecars(proj_root)` (`src/bathos/linter.py:49-58`) unchanged so `linter.py` and `tests/test_linter_sidecar_walk.py` stay untouched. When `check_stoichiometry == True and sidecar_path == ""`, iterate `iter_project_sidecars(proj_root)` and pre-classify each `discovered_path` via raw `tomllib.loads` against `SIDECAR_KIND_TABLES = ("experiment", "benchmark", "validation", "debug")`, `PROJECT_CONFIG_TABLES = frozenset({"project", "remotes", "slurm", "obligations", "claim", "enforcement", "gate", "provenance", "stepback", "defaults", "bearings", "instruments"})`, `NON_SIDECAR_ARTIFACT_TABLES = frozenset({"claim", "attestation", "parity"})`, and `SUBMIT_CONFIG_SIDECAR_TABLES = frozenset({"cluster"})`. After enforcing `[stoichiometry]`/`[reagents]` prohibition BEFORE any skip check, skip (`status="skipped"`) legitimate project/subdirectory `.bth.toml` configs (including `[bearings]`/`[instruments]`), non-sidecar `.bth.toml` artifacts (`claim.bth.toml`, `*.attestation.bth.toml`, `parity.bth.toml`), comment-only archived `<stem>.bth.toml` stubs (`not data and bathos.artifact_archive.parse_stub(discovered_path) is not None`), and `[cluster]`-only submit-config `<stem>.bth.toml` sidecars (`bool(data) and set(data) <= SUBMIT_CONFIG_SIDECAR_TABLES`), while parsing directory-level `scripts/experiments/.bth.toml` and `scripts/benchmarks/.bth.toml` as sidecars, failing closed on any illegal `[stoichiometry]`/`[reagents]` placement (including paired with `[bearings]`, `[instruments]`, `[cluster]`, or an archive stub), failing malformed/misplaced `<stem>.bth.toml` or `.bth.toml` files (empty `.bth.toml`, non-stub empty `<stem>.bth.toml`, stub+`[experment]`, `<stem>.bth.toml` `[bearings]`/`[instruments]`, `.bth.toml` `[cluster]`, `[cluster]`+`[experment]`) via `parse_sidecar`, and failing closed when `stoichiometry_checked_count == 0 and stoichiometry_failure_count == 0` (`stoichiometry_failure_count = 1` with descriptive `result_dict["error"]`); explicit `--sidecar-path` (`sidecar_path != ""`) always bypasses discovery skip rules and calls `parse_sidecar` directly (failing closed on `--sidecar-path .bth.toml`, archived stubs, and `[cluster]`-only sidecars). Leave bare `bth check` (neither flag set) 100% untouched for freshness/drift while always including `stoichiometry_results` and `stoichiometry_failure_count` in `check_tool`'s response dict. `bth run` (`prereg.gate_check -> validate_sidecar`) enforces stoichiometry and reagent checks and blocks with `GateErrorCode.SIDECAR_INVALID`, while `bathos.config.env_override("BTH_STOICHIOMETRY_WARN_ONLY")` provides emergency rollback inside `validate_sidecar` by downgrading semantic `ValidationError`s to warnings (parse-time `SidecarError` and explicit `bth check --check-stoichiometry` stay fail-closed).
6. **D6 — Exact `Decimal` reagent amortization**: Keep `pack_rxns` strictly `int` and parse `[reagents.<name>]` independently of wall-time `[budget]` (`BudgetBlock`, `src/bathos/sidecar.py:93-104`), evaluate all amortization math (`packs_required` via `Decimal` `ROUND_CEILING`, `unused_rxns_dec`, `waste_fraction = unused_rxns / purchased_rxns`, `total_cost_dec`) and ratio bound checks via exact cross-multiplied `Decimal` inequalities before `float(...)` conversion, failing closed on any exceeded bound or cost bound declared without `pack_cost_usd`.
7. **D7 — Self-contained `verify_citations --strict-coords`, dual tool wiring, and error taxonomy**: Require `<sources_dir>/manifest.json` (64-hex SHA-256 of raw `.numbered.txt` bytes), `[source: <name>.numbered.txt, sha256: <64-hex>, Page <page_num>, Line <line_start>[-<line_end>]]` markdown citation tags, contiguous multi-line `>` blockquote binding, NFKC + curly-quote/soft-hyphen normalization + de-hyphenation before `" ".join(text.split())`, and strict missing-line-gap / duplicate `(page, line)` / uncited-blockquote errors. Fail closed on empty normalized blockquote bodies and strip trailing `[source: ...]` attribution lines only when no non-tag prose precedes or follows them; register both `verify_citations_tool` (`registry="bathos-cli"`, `cli_name="verify-citations"`) and `mcp_verify_citations_tool` (`registry="bathos"`, `@traced_tool`, preserving non-empty `"error"` when `ok=False`), update `src/bathos/cli_cyclopts.py:56-159`, `src/bathos/mcp.py:7262-7371` (`_WIRED`), and `tests/test_cli_flag_contracts.py:235-240` alongside fixing the five stale `bth check` doc lines across `DOC_SURFACES` and regenerating `src/bathos/agent_plugin.json` (`uv run cisternal assets snapshot --manifest .praxia/manifest.toml --out src/bathos/agent_plugin.json`) plus `plugin/` (`uv run bth plugin repo-bundle`), and add `BathosErrorCode.CITATION_INVALID` + `RESOLUTION_HINTS` + `CitationVerificationError(BathosError)` + `EXCEPTION_TO_CODE` in `src/bathos/errors.py` (automatically shaped into `error_code="citation_invalid"` by `traced_tool`'s `except BathosError` handler at `src/bathos/mcp.py:222-233`).

  - **DAG validation & stage transition equations (`src/bathos/stoichiometry.py`)**:
    - Validate topological order via Kahn's algorithm across `StageKind = {"input_molecules", "enzymatic_species_cleanup", "colony_cfu", "barcode_collision", "founder_inoculum", "pcr_template_molecules", "bulk_fluorometry", "phix_adjusted_net_reads"}`. Require `len(stages_of_kind["input_molecules"]) >= 1`, `depends_on == ()` for `input_molecules`, and `len(depends_on) >= 1` for all other kinds; unknown parent stage names or cycles emit `ValidationError`.
    - Merge rule for `len(depends_on) > 1`: `entities_in = sum(parent.entities_out)`, `tracked_barcodes_in = sum(parent.tracked_barcodes_out)`, `species_in = union(parent.species_out)`.
    - State `(entities, species_present, tracked_barcodes)` per stage kind:
      - `input_molecules`: `entities_out = molecules`, `species_out = frozenset(species)`, `tracked_barcodes_out = molecules`.
      - `enzymatic_species_cleanup`: `ENZYME_REMOVES_SPECIES = {"DpnI": frozenset({"methylated_circular_vector"}), "linear_selective_nuclease": frozenset({"linear_partial_ligations"})}`; if `enzyme` is non-empty and not in `ENZYME_REMOVES_SPECIES` and `removes_species` is empty, emit `ValidationError`; `removed = ENZYME_REMOVES_SPECIES.get(enzyme, frozenset()) | frozenset(removes_species)` (if `enzyme == ""` and `removes_species` is empty, emit `ValidationError`); `entities_out = entities_in * retention_fraction`, `species_out = species_in - removed`, `tracked_barcodes_out = tracked_barcodes_in * retention_fraction`.
      - `colony_cfu`: if `efficiency is not None`, `entities_out = entities_in * efficiency`; else require `colony_cfu <= entities_in` (else `ValidationError`) and set `entities_out = colony_cfu`; `species_out = species_in`; `tracked_barcodes_out = entities_out`.
      - `barcode_collision`: require `entities_in > 0` and `barcode_diversity > 0` (else `ValidationError`); compute `per_clone_collision_prob = -math.expm1(-entities_in / barcode_diversity)`, `expected_duplicate_fraction = 1.0 - (barcode_diversity / entities_in) * (-math.expm1(-entities_in / barcode_diversity))`, `tracked_barcodes_out = barcode_diversity * (-math.expm1(-entities_in / barcode_diversity))`, `entities_out = entities_in`, `species_out = species_in`. If `per_clone_collision_prob > max_collision_prob`, emit `ValidationError`; else if `per_clone_collision_prob >= effective_warn_prob`, append warning string. When `barcoding_mode == "pre_barcoded_vector"`, require at least one `barcode_collision` stage whose `depends_on` includes a `colony_cfu` stage (or ancestor) and evaluate collision on its `entities_in` (failing closed with `ValidationError` if absent); when `barcoding_mode == "primer_pcr"`, transformation pre-barcoded collision is `0.0` (no `barcode_collision` stage required, while any declared `barcode_collision` stage still evaluates the Poisson formula above).
      - `founder_inoculum`: if `sampling_fraction is not None`, `inoculum_out = entities_in * sampling_fraction`; else require `inoculum_cells <= entities_in` (else `ValidationError`) and set `inoculum_out = inoculum_cells`; `entities_out = inoculum_out`, `species_out = species_in`, `tracked_barcodes_out = tracked_barcodes_in * (-math.expm1(-inoculum_out / tracked_barcodes_in))`.
      - `pcr_template_molecules`: `entities_out = entities_in * copies_per_cell * lysis_recovery_yield * pcr_aliquot_fraction`, `species_out = species_in`, `tracked_barcodes_out = tracked_barcodes_in * (-math.expm1(-entities_out / tracked_barcodes_in))`.
      - `bulk_fluorometry`: pass-through QC stage (`entities_out = entities_in`, `species_out = species_in`, `tracked_barcodes_out = tracked_barcodes_in`).
      - `phix_adjusted_net_reads`: require at least one `pcr_template_molecules` ancestor in the DAG (else `ValidationError`), compute `net_reads = raw_reads * (1.0 - phix_fraction) * qc_pass_fraction`, `effective_target = target_reads if target_reads is not None else net_reads`, enforce `ancestor_pcr_template_molecules >= min_template_ratio * effective_target` (using minimum `entities_out` among direct/nearest `pcr_template_molecules` ancestors when multiple merge, else `ValidationError`), enforce `net_reads >= target_reads` when `target_reads is not None` (else `ValidationError`), and enforce `reads_per_barcode = net_reads / tracked_barcodes_in >= min_consensus_reads` (else `ValidationError`); `entities_out = net_reads`, `species_out = species_in`, `tracked_barcodes_out = tracked_barcodes_in`.
  - **Cleanup species enforcement**: Define `DISALLOWED_CONTAMINANTS_BY_STAGE_KIND = {"colony_cfu": frozenset({"methylated_circular_vector"}), "bulk_fluorometry": frozenset({"methylated_circular_vector", "linear_partial_ligations"}), "pcr_template_molecules": frozenset({"methylated_circular_vector", "linear_partial_ligations"}), "phix_adjusted_net_reads": frozenset({"methylated_circular_vector", "linear_partial_ligations"})}`. If `stage.forbidden_species is not None`, use `frozenset(stage.forbidden_species)`; whenever `species_in & disallowed` is non-empty at any of those stages (whether or not `bulk_fluorometry` is present), emit a blocking `ValidationError`.
  - **Weighted subpool strata sizing**: When `stoichiometry.subpools` is non-empty, convert `w_i = Decimal(str(subpool.weight))`, `total_w = sum(w_j)` (`weight_i > 0`, finite), resolve `min_group_size_i = subpool.min_group_size if subpool.min_group_size is not None else stoichiometry.min_group_size` (emit `ValidationError` if `None`), set `min_i = Decimal(min_group_size_i)`, and evaluate `actual_d = Decimal(str(actual_pool_size))` against the minimum `colony_cfu.entities_out` (if any `colony_cfu` stage exists) and the minimum `phix_adjusted_net_reads.tracked_barcodes_in` (if any `phix_adjusted_net_reads` stage exists). Emit blocking `ValidationError` iff exact cross-multiplied `actual_d * w_i < min_i * total_w` holds for any subpool `i`, computing `required_total = float(max((min_i * total_w) / w_i))` and `allocated_i = float(actual_d * w_i / total_w)` strictly for diagnostic messages and reporting (eliminating IEEE-754 and 28-digit `Decimal` division drift).
